# P06 分阶段评分的条件 Pro 升级与费用预检（2026-09-14）

阶段158沿用已确认的 C13/B26 升级条件：只有 Flash 明确请求、较高能力能解决，且预计总分改变至少 8 分或关键身份/资格/主角色/存在/国家/网络相关状态可能改变时，才使用 Pro。分阶段事实输出不重做；最终 Pro 请求由同一批有来源指纹的阶段结果生成，按 **Pro 自己的实际序列化字节和独立费用合同**预检。若单请求超界，原 Flash 结果已保存、公司维持技术未完成；不因补量改判。Pro 响应也在归一化和评估缓存之前按模型/路由/付费哈希追加保存，跨进程可由其精确合同复用。

无付费验证：151事实/151本轮来源的合成超限公司在真实 PostgreSQL 产生4个事实阶段、Flash 最终评分及触发的 Pro 最终评分，共6次本地假模型响应；最终响应行分别对应 Flash 与 Pro，结果 `escalated=true`。另一进程重建阶段和最终判断，模型调用及新增用量均0，并识别 Pro 评估缓存合同。Pro 保存失败后不执行后续请求，也不对同一动作自动重买；阈值7分且无关键状态变化的夹具只调用 Flash。完整图合成入库和原单次评分路径仍通过。真实提供方、搜索、SMTP、token、API credits及现金消耗为0。

只读整次预检仍为 `totalRunBoundUsd=null`。仅作为**四阶段合成夹具**的算术示例，以现行每次评分保守上界 USD1.416561 计算：4阶段+Flash最终评分为 USD7.082805；若触发一次 Pro 最终评分为 USD8.499366。后者与已批准的 S01 市场计划 USD10.622880 相加为 USD19.122246，超过当前剩余 USD17.675596 达 USD1.446650，还未计其他必需阶段。实际公司、阶段数、条件复核、搜索及备用供应商仍无完整整次上界，不能启动真实付费业务。

边界：模拟 Pro 输出只证明请求、恢复、状态和成本接线，不证明真实语义判断或盲审质量；备用提供方实际接管仍需独立路由合同。最终结果与阶段保存的真实账单匹配、用户实际采用及自然语言到合格线索闭环继续待验收。冻结哥伦比亚测评不重跑、不改写。
