# A26 产品每周汇率有效期边界修复（阶段 234）

状态：已实现并完成无付费回归；不改变 A26 固定验收汇率、USD50 隔离额度、费率或模型路由；真实 A11 闭环仍未通过。

按 A26，隔离验收继续只读取已存的 ECB `ecb-cny-usd-2026-09-11` 版本，日历年龄不使该固定验收版本失效，本阶段没有再次抓取汇率。普通产品每周共享抓取官方 ECB 参考；抓取时仍拒绝参考日已满七天的数据，成功存入的快照从**实际取回时间**起至多可用于七天，过期继续阻止人民币计价的付费请求。原实现从参考日计算有效期、却从成功抓取时点计算下次周刷新：官方参考日早于抓取日时，两者之间可能出现尚未调度刷新而汇率已过期的空档。现在费用预留及页面状态使用同一取回时间截止。

成功抓取的调度还以**库内实际保留快照**为准：如果官方再次返回同一内容、追加式快照不插入新行，就在原快照到期至少一小时前重查，避免把重复抓取误认为新快照。若来源持续不更新或取得失败，沿用已有每小时退避及过期暂停；接近原快照到期时可能不足七天就再检查一次，不承诺供应商一定按周发布新参考。验收固定版本不参与此普通产品刷新。

验证：5 个受影响测试文件共 23 项边界和重复来源用例通过；全量 1,052 项/208 文件、TypeScript、变更文件 ESLint、Next.js 本地生产构建通过。测试传输为合成响应，零官方 HTTP 抓取、零付费模型/API 调用、零邮件、零新增预算预留；现有真实验收占用 USD23.520920/50 和十笔费用不完整记录保持不变。该修复不解除已观测的 S01 参数 404，S02 仍待按 A11 确认；条件搜索费率与 Gemini 工具用量上界仍各自在到达时按 A25 暂停。
