# G09 验收资料原件的显式保存

## 产品工作流

在已有 Skill 验收包页面，账号先查看服务器从本组任务附件和成功读取资料回执派生的原件清单，再点击“保存原件副本”。客户端只能提交审核包和预览哈希，不能指定资产或其他账号。预览不写副本；保存处于一个账号事务中，文件不匹配会回滚整组写入。已有副本重新核对字节后复用。

副本不取消当前账号、共享权限、资料撤回及冻结状态检查，不产生人工审核结论，不授予来源或生产资格，不启用 Skill。现有存储的单文件 50 MiB 限制在写入前检查。

## 当前证据

- 80 项定向测试、TypeScript 与定向 ESLint 通过。
- 实际文件和一次性数据库验证通过：附件与读取资料合并、预览零写入、跨账号/额外资产字段/旧预览拒绝、超限零写入、后续文件损坏导致整组回滚、保存和重复复用、原文件丢失后的副本核对、共享撤回/账号停用/冻结撤销拒绝。
- 数据库夹具使用合成来源、无人工判断、无模型调用；五个回放类案例不构成完整五类质量验收。
- 日志：`tmp/ma24-explicit-original-capture-database-2026-10-19.log`；结果：`tmp/ma24-acceptance-originals-database-result.json`。
- 新编译镜像上的 HTTP 与 HTTPS 浏览器操作待验，本阶段不宣称页面端到端通过。

本次实现沿用既有 MA24-06 的审核与启用边界，不新增用户确认规则。G14–G20 与内网上线仍暂缓。
