# 普通 Worker 与 G09 共用任务租约

对应既有 MA24-06，无新增用户确认。只推进 G01–G13；G14–G20 与部署继续暂缓。

## 行为修改

- 普通后台 Worker 与 G09 正式候选任务使用同一个任务租约组件：数据库确认有效租约后执行，90 秒上限、20 秒续租，独立本地截止计时器发送取消信号。
- 本地窗口从数据库请求发出前计算，不把读取或续租响应延迟算作额外执行时间；续租不重叠，停止或到期后的迟到成功响应不能恢复窗口。
- 续租和执行边界使用数据库 `clock_timestamp()`，拒绝在事务开始时尚有效、实际已经到期的租约。续租同时拒绝暂停/取消和已停用账号。
- 观察到当前暂停/取消时，停止续租，在仍有效的租约内结算控制状态，保留已有部分回复。G09 不执行模型回调，继续维持隐藏任务、无用户消息和无记忆抽取的规则。
- 对过期但仍标为 running 的任务，控制入口直接写入 paused/cancelled，避免等待已无有效所有者的任务来结算。
- 普通 Worker 传输失败保持不自动重放，通过原有部分完成路径保存连接中断提示。

## 验收范围

定向测试覆盖初次读取延迟、续租延迟、迟到响应、窗口到期与控制结算。实库夹具使用隔离新库、真实任务 SQL 与编译后的普通 Worker，仅替换远端 SDK 和无关调度器；模型与外部业务调用为零。

29 项定向测试、完整类型检查和 8 文件 lint 通过。迁移至 169 的隔离新库整轮输出 `freshClusterPilot: passed`，包含实际续租、编译 Worker 四种场景、G09 控制结算和历史候选提交后 SIGKILL/自然到期/新进程恢复。临时数据库容器和测试进程已退出；原有三个服务保持运行。原始外层 shell 的退出码句柄未恢复，不以猜测的退出码充当证据；最终通过记录在清理完成后输出。

完整数据库结果与源码/日志摘要见[阶段证据](evidence/ma24-g09-shared-agent-run-lease-2026-10-21.json)。首轮失败记录保留：旧准入测试任务在独立图验证期间自然到期，导致后置取消测试先被租约拒绝；修正夹具为新建独立任务，没有放宽过期检查。
