# G09 版本化信任登记事务存储

## 已实现

- 迁移 157 新增不可修改的公共密钥登记版本和当前版本指针，不预置任何登记或私钥。
- 发布函数及当前指针写入取得排他事务锁；读取函数在已验证的账号事务内取得共享事务锁，锁持续到调用方提交或回滚。
- 读取只允许 READ COMMITTED，取得锁之后另起查询读取当前版本，再校验既有严格登记格式及规范摘要。避免等待发布时仍读取旧事务快照。
- 应用和采集器仅有 SELECT 权限，不能发布登记或修改指针。管理员禁用触发器等特权绕过不属于此保证。
- 原文件登记验证器复用抽出的同一格式定义，默认字段和摘要算法不变。

## 实际验证

`node scripts/run-tsx.cjs scripts/verify-skill-trust-registry-database.ts` 在本机新建独立 `ma24_registry_<随机值>` 数据库，实际安装迁移 157，验证后删除该库。测试公钥现场生成，未加载或保存生产私钥。

1. 无账号绑定、跨账号和未登记读取拒绝。
2. 同一测试公钥从 enabled=true 发布为 false，发布连接被准确的读取 PID 阻塞；读取事务内版本及 enabled 保持不变，提交后下一事务读到禁用版本。
3. 反向顺序中，读取等待尚未提交的发布，发布提交后读到新版本。
4. 应用及采集器角色不能发布或删除当前指针。
5. 版本修改/清空、REPEATABLE READ、错误摘要和额外格式字段均被拒绝。

原文件签名验证器 22 项回归通过；全项目 TypeScript 检查通过。结构化收据见 [数据库验证](evidence/ma24-g09-trust-registry-storage-2026-10-19.json)。
