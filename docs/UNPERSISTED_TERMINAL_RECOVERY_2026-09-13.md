# 未保存结果的旧终结检查点恢复

阶段79实现 O01/A06 的一个明确历史分支：检查点已经没有下一节点、没有最终 result，但明确记录 processing-incomplete，且保留原计划、playbook、run/workspace、候选/校正/评分、证据上下文、费用与使用记录。缺失必要记录或仅角色待定不推断成这类任务。

执行器在用户通过现有失败任务确认恢复后，先核对 checkpoint 用户/action/原计划，再阻止 reserved/unknown/bound-exceeded 费用，最后核对原运行国家、工作区用户、action/thread关联。数据库已有完成运行、deliveryCounts、保存指纹、评分记录或动作结果时拒绝；不改写历史保存数据。通过后只把原检查点转到缺项恢复节点，保留证据/已完成单项/费用并标记 terminalRecoveryOnly。

这一恢复模式只做原有缺项校正/评分及后续审核/保存。即使目标仍不足，也停止为明确缺口，不重新搜索或重做发现补证节点；再次不完整仍保留恢复资格。必要的校正Agent内部补证仍受原契约及费用门禁控制。本次没有执行该类付费请求。
