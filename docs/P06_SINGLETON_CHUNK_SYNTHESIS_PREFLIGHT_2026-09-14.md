# Stage 210: complete singleton chunk synthesis preflight

`assembleQualificationSingletonChunks` now accepts a long source or finding only when the original full-text SHA256, per-unit checkpoint stream, every original evidence ID, exact chunk count, index order and contiguous Unicode code-point offsets all match the supplied plan. It runs the strict output/citation validator on every chunk, reconstructs the complete original text from the planned excerpts, and rejects a missing, swapped, altered or foreign-cited part. The assembled result retains each numbered bounded interpretation and original IDs. If **any** part is uncertain, overall materiality remains uncertain; a material summary cannot erase an uncertain segment. This is local interpretation assembly, not proof the outputs were persisted, evidence corroboration or final eligibility.

A synthetic >80,000-character source produced multiple exact-wire chunks. Complete outputs assembled in order; a missing output, swapped outputs, changed source text, changed original citation ID and damaged offset were each rejected. The original source was not mutated. Five focused tests, all **1,031 tests in 208 files**, TypeScript, focused ESLint and the Next.js production build passed. No provider call, paid reservation, database mutation, customer task or email was made.

The assembled summaries are **not yet wired into `LeadQualificationAgent` or the final score request**. Very many chunks can still create a final payload too large for the approved model request; that must be handled by bounded hierarchical synthesis or retained as incomplete, never scored as a business rejection. Real model semantic fidelity and whole-run cost remain unverified. P06 and A11 overall acceptance stay open.

Efficiency: one synthetic long-source input and five local failure/coverage variants yielded one valid complete assembly and five rejected incomplete/mismatched cases, all used for local preflight validation; downstream product use and customer adoption remain unknown. Model tokens, paid API credits, cash, external retries and mail were zero. Focused test execution was about one second, full regression about twenty seconds; real provider latency is unknown.
