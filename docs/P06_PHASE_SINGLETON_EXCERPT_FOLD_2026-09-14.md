# P06 分阶段超长单来源摘录的受控折叠（阶段166）

分阶段事实请求以前在单个纠正事实与其来源摘录超过 57,344 字节时，于外发前停为技术待恢复。现行规划器仅在完整实际请求超限后，对**所有关联事实均为已支持、且种类为产品线、品牌关系、商业动作、合作路径或公司规模**的来源摘录尝试保留首尾各 600 个 Unicode 码点，标明省略长度和原摘录 SHA-256。纠正事实原陈述、状态、来源 ID/类型/URL、引用关系和产品 SQL 中的完整证据快照不修改。身份、目标国存在、联网活动、角色、其他未分类、冲突或未知事实，以及无关联来源均不折叠；折叠后实际请求仍超界则继续在付费前暂停。

事实阶段的指令禁止把省略中段当作佐证、反证或已解决冲突；若原文缺失影响重要性判断，应标为不确定。最终评分输入额外列出 `foldedEvidenceIds` 并提示阶段摘要并非独立证据，不得据此升级资格门禁。阶段来源指纹仍基于原完整纠正事实和本轮证据，付费请求及完成检查点采用折叠后的实际合同；旧合同完成行不能冒名复用。模型若违反指令，仍须由真实语义验收发现，本地字节测试不能保证语义正确。

隔离单公司夹具以一条 100,000 字符非关键已支持来源验证：完整摘录在阶段请求中折叠，实际 DeepSeek 序列化请求全部不超过 57,344 字节；原候选保持不变，来源 URL/类型和原纠正陈述保留，原文变化使来源指纹变化。关键角色、冲突产品事实、未知种类和无关联超长来源四条路径均在传输前拒绝。最终综合保留原陈述并把折叠来源标记传给最终评分。阶段检查点跨进程 SQL 脚本通过且清理夹具。
