# G09 验收任务与工具日志锁

## 附件元数据锁：已接线，含附件完整组合待验

迁移 145 的 `lock_skill_attachment_sources(uuid[])` 仅允许锁定当前账号可访问的原件。从原件派生文档 ID，依次锁文档、原件和当前解析版本 SHARE，阻止权限、登记状态及解析版本更新。参数最多 100 个不重复、非空 ID；空数组返回 0。仅应用角色可执行，不新增表写权限。

[一次性数据库验收](evidence/ma24-g09-attachment-source-locks-2026-10-16.json)实际观察三类更新等待及释放后完成，跨账号私有原件与重复 ID 拒绝。材料入口现从已锁定任务输入派生附件，沿用每任务最多 20 个约束，去重排序后每批最多 100 个加锁并核对数量；无附件不调用新函数。21 项回归、120 附件分批、类型/lint 和实际六类任务/日志/附件并发验证通过。包含登记附件的完整五类组合正在运行，尚未判通过。既有权限/内容守卫在锁后复查；不保护文件字节，也不覆盖发布指针、事实审核或全部检索节点。

## 原始会话锁：已接线，完整组合已通过

迁移 144 增加内部 `lock_skill_task_origins(uuid[])`：按当前账号任务派生会话，先锁账号 SHARE，再锁会话 UPDATE 和已有消息 SHARE。会话 UPDATE 同时通过外键阻止消息追加，包括可能影响历史窗口的补插。仅应用角色可调用，未增加表写权限。空数组返回 0，最多 100 个不重复且非空 ID；跨账号或缺失任务拒绝。

[一次性数据库验证](evidence/ma24-g09-task-origin-locks-2026-10-16.json)已通过四类写入阻塞、释放后恢复、跨账号/重复/空参数拒绝和重复安装。材料入口通过任务日志锁助手先调用此函数，核对锁定数量；缺迁移或数量不符立即拒绝。18 项定向回归、类型/lint、接线后的实际数据库及完整五类组合通过；完整组合早于附件锁接线，二者分别验收。

`revalidateLockedSkillAcceptanceMaterials` 在读取任何题目私有材料前，从已存审核包的历史、安全、前瞻引用派生任务 ID。历史两臂必须关联同一任务；缺引用、未知来源类型或不可见任务均拒绝。

同一账号事务先按 ID 顺序取得任务 UPDATE 锁，再按 ID 顺序取得已有工具日志 SHARE 锁。任务锁通过外键检查阻止新的工具日志插入；日志行锁阻止已有输入、输出和状态被修改。随后才运行既有五类材料重建与复查。锁保持到调用方事务结束，不能把返回值当作持久授权。

定向 16 项测试、全仓类型检查及定向 lint 通过。一次性 pgvector/pg16 数据库实际观察到任务更新、日志更新和日志追加三类事务等待持锁方，释放后全部继续；跨账号任务锁请求拒绝。未增加数据库权限、未调用真实模型。

任务日志锁与后续会话锁版本分别通过完整五类组合的材料重建、缺审核拒绝及开发审核写入/撤销；最新含附件锁场景另行运行。本阶段不锁定日志所引用的全部知识、邮箱或客户记录，不认证生产采集器，不开放自动启用。`sourceRevocationsLocked`、`collectorProvenanceVerified` 和 `automaticActivation` 仍为 false。
