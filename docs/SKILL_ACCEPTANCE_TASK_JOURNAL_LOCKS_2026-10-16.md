# G09 验收任务与工具日志锁

## 原始会话锁：已接线，完整组合待验

迁移 144 增加内部 `lock_skill_task_origins(uuid[])`：按当前账号任务派生会话，先锁账号 SHARE，再锁会话 UPDATE 和已有消息 SHARE。会话 UPDATE 同时通过外键阻止消息追加，包括可能影响历史窗口的补插。仅应用角色可调用，未增加表写权限。空数组返回 0，最多 100 个不重复且非空 ID；跨账号或缺失任务拒绝。

[一次性数据库验证](evidence/ma24-g09-task-origin-locks-2026-10-16.json)已通过四类写入阻塞、释放后恢复、跨账号/重复/空参数拒绝和重复安装。材料入口通过任务日志锁助手先调用此函数，核对锁定数量；缺迁移或数量不符立即拒绝。18 项定向回归、类型/lint 及接线后的实际数据库通过；接线后的完整五类组合正在运行，未判通过。

`revalidateLockedSkillAcceptanceMaterials` 在读取任何题目私有材料前，从已存审核包的历史、安全、前瞻引用派生任务 ID。历史两臂必须关联同一任务；缺引用、未知来源类型或不可见任务均拒绝。

同一账号事务先按 ID 顺序取得任务 UPDATE 锁，再按 ID 顺序取得已有工具日志 SHARE 锁。任务锁通过外键检查阻止新的工具日志插入；日志行锁阻止已有输入、输出和状态被修改。随后才运行既有五类材料重建与复查。锁保持到调用方事务结束，不能把返回值当作持久授权。

定向 16 项测试、全仓类型检查及定向 lint 通过。一次性 pgvector/pg16 数据库实际观察到任务更新、日志更新和日志追加三类事务等待持锁方，释放后全部继续；跨账号任务锁请求拒绝。未增加数据库权限、未调用真实模型。

任务日志锁版本的完整五类组合已通过材料重建、缺审核拒绝及开发审核写入/撤销；此结果早于原始会话锁接线，不替代后者正在运行的完整回归。本阶段不锁定日志所引用的全部知识、邮箱或客户记录，不认证生产采集器，不开放自动启用。`sourceRevocationsLocked`、`collectorProvenanceVerified` 和 `automaticActivation` 仍为 false。
