# G09 验收任务与工具日志锁

`revalidateLockedSkillAcceptanceMaterials` 在读取任何题目私有材料前，从已存审核包的历史、安全、前瞻引用派生任务 ID。历史两臂必须关联同一任务；缺引用、未知来源类型或不可见任务均拒绝。

同一账号事务先按 ID 顺序取得任务 UPDATE 锁，再按 ID 顺序取得已有工具日志 SHARE 锁。任务锁通过外键检查阻止新的工具日志插入；日志行锁阻止已有输入、输出和状态被修改。随后才运行既有五类材料重建与复查。锁保持到调用方事务结束，不能把返回值当作持久授权。

定向 16 项测试、全仓类型检查及定向 lint 通过。一次性 pgvector/pg16 数据库实际观察到任务更新、日志更新和日志追加三类事务等待持锁方，释放后全部继续；跨账号任务锁请求拒绝。未增加数据库权限、未调用真实模型。

完整五类组合接线回归仍在运行，未判通过。本阶段不锁定日志所引用的全部知识、邮箱或客户记录，不认证生产采集器，不开放自动启用。`sourceRevocationsLocked`、`collectorProvenanceVerified` 和 `automaticActivation` 仍为 false。
