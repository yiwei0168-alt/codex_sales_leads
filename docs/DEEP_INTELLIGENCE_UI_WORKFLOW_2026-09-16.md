# 深色情报中枢 UI 工作流（UI-D12）

## 目标与边界

全站默认视觉统一为面向渠道销售与证据决策的深色情报工作台。Night `#081018` 作为页面底色、Slate `#111C27` 作为主要面板、Fog `#DDE7EF` 作为正文、Signal `#31D6A0` 表达已验证/关系/成功、Action `#4E8DFF` 表达主操作与当前焦点。系统字体栈不产生远程字体请求。

本阶段不改变任何公开 API、DTO、数据库、路由、权限、成本门禁、业务状态或事件调用路径。保留 `globals.css` 与 `ipados.css`，由 `intelligence-theme.css` 作为最后加载且以根 class 作用域隔离的主题层。唯一新增交互状态是移动导航开关，不持久化且不触发业务请求。

## 表现层流程

1. 根布局最后加载主题层，并在 `body` 设置 `intelligence-theme`。
2. 桌面应用外壳保留固定左侧导航与顶部上下文栏；当前导航使用 Signal 信号轨。
3. 980px 以下侧栏变为模态抽屉。菜单按钮负责打开；导航选择、关闭按钮、遮罩或 Escape 负责关闭；共享焦点管理约束 Tab，并在关闭后恢复打开按钮焦点。
4. 620px 以下内容占满可用宽度，触控目标至少 40px；线索、市场概览和任务摘要表格使用 `data-label` 转换为信息卡。渠道画布及机会看板保留局部横向滚动能力。
5. 面板、按钮、表单、标签、AI 助手、任务、知识库、邮箱、预算、登录、抽屉与弹窗统一使用深色令牌；警告和错误保留独立语义色。
6. `prefers-reduced-motion` 下关闭非必要动效；所有键盘焦点使用 Action 高对比轮廓。

## 2026-09-16 验收结果

`npm test` 通过 213 个测试文件、1078 个测试；`npm run typecheck`、`npm run lint`（仅保留 11 个既有 warning）、`npm run build` 均通过。Playwright 在 1366×900 与 390×844 共执行 24 个项目：22 通过，2 个为仅适用于移动断点而在桌面按设计跳过。新增检查覆盖移动抽屉焦点约束、Escape/遮罩关闭、焦点恢复、移动表格字段完整和页面级无横向溢出。

已认证生产构建脚本在两个目标视口各完成 34 项、合计 68 项真实本地页面/API/隔离数据库检查，覆盖九个导航视图、线索、渠道图、公司抽屉、预算与任务成本面板，生成 18 张实页截图；浏览器外部请求与非白名单写操作被拦截，付费调用 0、真实邮件 0，合成用户/工作区/公司均已清理且未修改客户记录。另生成 4 张隔离式新旧主题对比图。实际用户采用仍未知。

## 回退

移除根布局中的 `intelligence-theme.css` 导入及 `body` class 即可回到保留的旧视觉层。移动导航 TSX 结构可独立回退；它不影响任何业务数据或请求。
