# Memory audit and search-continuation ACL — stage 185 (2026-09-14)

Full migration replay runs migration 014's broad public-table CRUD grant before migrations 039 and 049. Those later migrations granted SELECT/INSERT to the application role but did not revoke the old UPDATE/DELETE. A read-only effective-role audit confirmed both `user_memory_audit` and `lead_search_continuation` were owner-writable and deletable. An owner could therefore alter private-memory history or the continuation lineage/excluded-domain snapshot even though product code only inserts and reads these records. Tenant RLS alone did not enforce append-only behavior.

[Migration 073](../db/migrations/073_memory_audit_search_continuation_acl.sql) revokes public/application privileges on just these two tables, then grants the application role SELECT/INSERT. It follows migration 014, preserves rows and RLS, and is idempotent on full replay. The SQL contains a compatibility rollback instruction that would reopen mutation access; no historical row is rewritten. The effective-role ACL audit now includes 18 billing, recovery, memory-audit and continuation tables. The memory and continuation SQL verifiers also attempt owner no-op UPDATE and DELETE inside savepoints and require permission denial, while continuing to test normal audit generation, proposal idempotency, tenant isolation and cascade deletion.

Local acceptance: before migration, the read-only audit rejected exactly these two tables with UPDATE/DELETE true. Two complete 001–073 migration replays passed. After each replay the 18/18 ACL audit, memory-audit verifier and continuation verifier passed; fixtures and schema changes in those verifiers rolled back. The full 1,021-test / 207-file suite, typecheck and changed-script lint passed. This stage made no external request, paid call, mailbox send or change to historical fees. It proves the tested application role cannot directly edit these records; it does not prove live business completion, provider invoice accuracy or all future database privilege paths.
