# MA15 前端精简验收（2026-09-21）

范围：[确认规则 MA15-01～07](CONFIRMED_PRODUCT_RULES.md)、[实施工作流](FRONTEND_SIMPLIFICATION_PLAN_2026-09-21.md)。四阶段分别提交；确认、实现和验收分别记录。

## 已实现

- 半透明紫色导航与浅灰画布，白色阅读区；唯一共享颜色/字号变量。248px 可收起侧栏，960px 以下抽屉；正文与输入 16px、导航 15px、辅助文字 14px、元数据不低于 13px。桌面控件至少 40px，移动端 44px。
- 一个新对话按钮、三个业务入口、帮助和账户菜单；市场/客户开发页签与国家/公司随 URL 恢复。`/knowledge`、`/development`、`/tasks`、`/settings`、`/help` 可直接访问；旧市场、任务详情、对话链接保留。
- 返回当前或最近可读取的对话；未发送对话文字只存应用内存，退出账户清理；主动新对话清空新对话输入。页面切换不创建记录，实际发送仍走原有消息服务。
- 知识库默认资料列表；完整保存文本阅读及返回、Markdown 表格自身滚动、原件/来源/私有历史版本；知识问答单列、引用可展开；管理员审核，个人记忆对普通账户仍可访问；上传按需打开，处理进度在资料区。
- 客户开发明确选择公司；批准卡展示实际邮件、收件人、正文、附件和删除对象；参数、版本与执行事件收在详情。任务记录包含与对话读取同一服务的最近对话任务。
- 模式 DTO/写服务/可发现 Agent 工具移除；旧 PATCH 返回 410 capability_removed，旧工具调用 unavailable 且明确未执行。迁移 103 仅取消历史列非空和默认值，保留历史模式/审计；新路径记忆仅记录已有业务目标。

## 边界与遗留

- 125% 使用布局视口除以 1.25 加 deviceScaleFactor=1.25 的等效浏览器缩放几何；未将其写成浏览器工具栏原生缩放的人工验收。
- 旧版完整 verify-private-knowledge-isolation.ts 在既有 hybridSearch fixture 断言得到空结果，当前本地库启用 v3 release；新增全文接口的四项隔离断言已通过独立运行。未改变旧检索行为或声称该旧全量脚本通过。
- 资料正文来自保存的检索片段，可能重叠；界面明确提示，原始排版通过原件查看。没有臆造缺失文本或版本。
- 迁移 103 只在本地数据库执行；本轮没有发布远端服务或迁移远端数据库。
- 原有未跟踪实验产物保持原状，未纳入提交；未生成开发成本/效率台账。
