# 决策路由阈值校准

用户指令“校准阈值”，规则 HYBRID-03。承接 [首轮试点](DECISION_ROUTING_PILOT_2026-11-09.md)，只校准建议放行门槛，不修改模型提示词、标签、付费请求契约或原始收据，不调用新模型，不开启当前产品。

## 方法与边界

每个模型使用相同 63 条开发样本。另 64 条上一轮已经暴露的保留样本只用于回归展示；选择器收到任何非 development 样本都会拒绝。两组都来自开发者标注的合成模板家族，不是独立自然业务验收。

固定流程和 interpreter 分别选门槛。候选 top probability 为 0.50–0.95、步长 0.05，第一名与第二名概率差为 0.05–0.50、步长 0.05。仅在开发样本无错误放行时最大化正确放行数；并列时依次取更高概率、更大差值。每条路径至少需要 8 条正例、2 个正例模板家族和 16 条负例，且放行正例覆盖至少 2 个家族；不足时禁用该路径的建议。该支持量是工程下限，不是统计可靠性证明。

历史、附件、有效政策和知识集合范围受限的请求仍不进入新模型路由；校准评估同样执行此限制。模型原始 choice 为 uncertain 或 dynamic_agent 时，不因降低阈值而升级到简单路径。confidence 不作为独立正确率证据。

配置版本 `hybrid-decision-thresholds-v2`；以下数值是开发集选择结果，不是用户指定值。

| 模型 | 路径 | 最低 top probability | 最小前两名差值 |
| --- | --- | --- | --- |
| Jev 1.14 | 固定流程 | 0.50 | 0.05 |
| Jev 1.14 | interpreter | 0.85 | 0.50 |
| OpenAI Decisions | 固定流程 | 0.55 | 0.15 |
| OpenAI Decisions | interpreter | 0.55 | 0.35 |

这是**决策门槛校准**，不是概率校准；0.50 不代表“正确率 50%”。较低固定流程门槛只适用于可推翻建议，不能据此自动执行业务操作。主模型仍负责核对全部要求、公司与参数、证据及工具权限。

## 收据与历史可复现

- 新任务保存 `{response, policyVersion}`，保留原始提供方响应；指标和提示均带阈值版本。
- 旧的直接 response 收据按 v1（0.9 / 0.2）恢复，不能被新门槛追溯升级；新版收据按保存版本恢复，未知版本回退，不重发模型请求。
- 保持请求契约和原 call key 不变，升级门槛不创建新的付费身份，也不重发 started/unknown 调用。
- 初次试点的 evaluate/report 脚本显式使用 v1，避免重跑报告时改写历史统计。新校准报告独立保存。
- 数值边界使用浮点表示误差级别的容差，确保 0.50−0.45 达到 0.05，而 0.50−0.450001 不通过。

复现命令：`node scripts/run-tsx.cjs scripts/calibrate-decision-routing.ts --check`。读取原始本地收据、核验身份和契约哈希，先选择开发集门槛，再读取暴露回归集；`--check` 检查提交配置与选择结果完全一致。不导入网络适配器、不新增调用。
