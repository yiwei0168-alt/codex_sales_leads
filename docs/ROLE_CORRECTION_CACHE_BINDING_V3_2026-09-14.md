# 公开角色校正缓存引用绑定 v3（阶段96）

角色校正的公开缓存允许同一公司的有效公开证据在新执行轮次更换证据 ID 后复用。旧绑定使用 URL、内容哈希和来源类型寻找新 ID；若同一页相同摘录产生不同标题的两条证据，两个键相同，Map 只保留最后一条，引用可能错绑到另一 ID。冻结哥伦比亚评测未改写，也没有证据表明其历史结果遇到这一碰撞。

现在证据指纹及引用重绑都包含完整标题和摘录，缓存依赖版本为 `role-cache-dependencies-v3`。缺少新字段的历史绑定返回 miss，需按原工作流重新判定，不把旧缓存强行当作有效；原缓存行不删除、不批量重写。已有 `isCurrentLeadScoringEvidence` 会校验内容哈希等于摘录 SHA-256，缺失或不匹配的哈希本来就不能进入当前评分证据。本修复针对的是**不同标题的同页同摘录项**，不是声称哈希校验缺失。

验收使用合成同 URL/哈希/来源、不同标题的两条当前证据：旧 ID 应绑定到相同标题对应的新 ID；标题、摘录、哈希变化和旧格式绑定都不得命中。跨进程 PostgreSQL 恢复脚本再次通过：校正仅第一进程执行，评分仅第二进程执行，100 条原证据与13合成额度保留；这仍使用合成业务适配器、真实图和数据库检查点，**不是**真实模型或最终入库的完整验收。全量896项测试/196文件、类型检查、生产构建、改动文件 lint 通过；生成工作流文档已按源码哈希更新并复核。无供应商调用、真实费用或用户采用。

缓存 v3 变更可能使少量旧快照少命中，带来将来重新判定的成本；现有费用门禁仍先于任何付费调用生效。回滚可恢复代码 v2，但旧绑定碰撞风险也会恢复；数据库无迁移。
