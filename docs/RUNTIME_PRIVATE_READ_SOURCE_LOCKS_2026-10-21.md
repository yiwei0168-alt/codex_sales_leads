# 候选只读日志的私有来源锁

既有 MA24-06；继续 G01–G13，不推进部署、G14–G20 或真实付费调用。

## 实现

`lockSkillRuntimeMaterialSources` 过去保留候选任务和工具日志锁，但没有独立从候选日志派生邮件/客户来源锁。来源锁依赖原任务的同类读取，无法支持候选将来的新增读取。

本轮把原任务的私有来源锁逻辑抽为 `lockSkillReadReceiptSources`，原任务和候选复用。候选任务/日志通过账号、任务规格、状态、只读效果和输入哈希检查后，才从权威工具日志派生来源 ID：

- 指定客户及整账户列表继续使用既有数据库来源锁函数，保留其客户、关联邮件和新增记录保护。
- 邮件按当前账号锁定；数量、唯一 ID 和具体返回 ID 均须匹配，不能仅凭数量通过。
- 来源锁保留在同一绑定租户事务中，不执行工具、不访问邮件服务器、不产生模型请求。
- 原任务来源与候选来源计数分开，不把候选任务 ID 伪装成原任务 ID。
