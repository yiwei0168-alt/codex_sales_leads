# G03/G04 中文自然纠正实际 Worker 链

## 发现与修复

实际本地 Qwen 在“我之前说我喜欢详细报告，那不对。纠正一下，我喜欢简短报告。”中，将旧内容输出为“我之前说我喜欢详细报告”。既有校验拒绝这段引导语并生成待核对记录，没有错误替换；但此类明确中文纠正无法自动完成。

第一次中文 Worker 联验因此退出 1。随后尝试不同内容的格式示例，实际模型仍输出同样引导语，第二次退出 1；无效示例已撤回。两轮原始响应及日志保留，不能改标通过。

现在只在模型判定为 correction、旧片段位于当前消息开头、且带固定“我之前说”或“I previously said”引导语时，尝试移除该固定前缀。其后必须保留完整第一人称命题，并在当前消息中唯一出现；新旧片段均须在非引用区，随后由**未放宽的原有校验**重新检查敏感内容、问句、归属与精确原文。未满足条件则仍进入待核对。

整理不生成新正文、不选择记忆 ID、不推断时间。数据库继续复核原用户消息、旧来源、账号、范围、唯一目标、冲突和有效期。回执新增 `framingNormalization`，记录 `leading-self-report-v1` 及整理前的模型旧片段，便于追溯。

## 实际通过范围

- 全新临时 PostgreSQL 迁移至 156，宿主机当前抽取/图谱 Worker；固定 Web 镜像 `ma24-pilot-web:d6ffb7a1` 仅用于既有登录/公司 HTTP 环境，不声称镜像已包含本次修复或迁移 157。
- 中文三个合成输入：本人偏好、自然纠正、客户引语；实际本地 Qwen chat 3 次。四次抽取 Worker `--once`（含空队列）通过，客户引语无观察入库。
- 原记录和纠正记录的业务有效日期仍为空，来源 messageId 对应各自用户消息；通知/outbox 各一次，正式事实/政策计数不变。
- 两条观察经实际图谱 Worker 投影到本机 Graphiti/Neo4j，第三次图谱 `--once` 为空；租约释放及一次投递核对通过。仅清理本轮 owner/observation UUID 对应图谱，临时集群自动删除。
- 英文另以一次实际本地请求复验自然纠正的精确原句契约，通过且没有触发整理；这不是英文 Worker/数据库链重验。
- 83 项定向回归、类型及 lint 通过；原始模型输出只保留在本地临时证据目录，公开收据使用 SHA-256。
