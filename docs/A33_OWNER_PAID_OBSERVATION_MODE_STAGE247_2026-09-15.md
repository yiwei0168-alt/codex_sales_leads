# A33 当前用户付费观察模式（阶段 247，2026-09-15）

## 决策与范围

产品当前仅由用户本人使用。用户明确批准当前阶段所有付费调用不设费用门禁，并进一步确认早期产品应优先保持流畅：不提前按费率合同或预算限制调用，只记录最终费用，积累一段时间后统一审查不合理环节。A33 仅对环境变量中精确指定的用户生效，默认关闭；A29 保留为历史规则但不再是当前开关。

## 实现

- `PAID_CALL_STAGE_OVERRIDE=A33` 与精确 `PAID_CALL_STAGE_OVERRIDE_USER_ID` 同时匹配时，`missing-tariff`、`expired-tariff`、费用合同边界、用户/任务预算、冻结及费率暂停均不阻止调用。
- 所有 A33 调用在网络前写入 `cost_bound_known=false`、`reserved_micros=0`。零仅表示“不声明预调用金额上界”，不表示免费；费用仍为未知，直到取得服务商报告或账单。
- 响应后保存可得的实际费用、token/API credits、延迟、重试、有效输出、下游使用和丢弃原因。非完整费用报告可提高观察占用，但不会制造“超出费率上界”的暂停。
- 未取消认证、租户隔离、A30 外发脱敏、服务商请求安全、相同请求并发以及已有成功输出防重复。供应商自身认证、额度、风控与 allowlist 仍可能拒绝请求。
- 对精确 A33 用户，OpenRouter 边缘返回 401/403/429/5xx 时允许继续 A32 的一次 Bedrock 同模型备用；备用失败后仍停止，不增加第三条线路。

迁移 076 已执行。真实 PostgreSQL 合成账本检查验证：一笔无费率调用以 0 预留和未知上界入账，合成响应报告 USD0.002 后观察占用变为 USD0.002，同一成功请求不能再次发送，测试数据已清理，真实供应商调用为 0。57 项聚焦测试、1,080 项全量测试、TypeScript、lint（0 错误、11 个既有警告）、生产构建、生成文档检查和生产依赖审计（0 漏洞）通过。真实调用产生的现金、语义质量、延迟、重试与下游利用率仍须在使用期内积累，之后按工作流阶段统一复盘；当前改动本身的外部调用、token、API credits、现金费用和有效业务输出均为零。

重启后的用户实测证明 A33 已进入运行态：OpenAI 主请求 2,117 bytes、2,278 ms，随后 Bedrock 备用请求 2,135 bytes、379 ms；两笔均为 0 预留、未知费用、0 有效/下游使用输出、0 SDK 重试。两笔都由 OpenRouter 返回 403，`routerAttempt=0` 且无上游尝试，说明失败发生在 OpenRouter 边缘而非模型供应商。当前密钥状态接口返回 200、非免费层、无密钥级金额上限及到期限制，因此密钥有效且不是密钥预算耗尽；剩余高概率原因是账户/工作区 Guardrail 的模型/供应商 allowlist、账户级预算、ZDR/隐私或内容过滤。普通调用密钥不是 management key，无法通过管理 API列出具体 Guardrail。该实测验证了“本地不拦截”，没有验证“外部网关放行”。

用户确认 OpenRouter 未主动设置限制后，使用完全公开、与知识库无关的最小 `Reply OK` 请求分别探测两条路线。OpenAI 请求 304 bytes、1,358 ms，Bedrock 请求 322 bytes、400 ms；两者均返回 403 `This model is not available in your region.`、`routerAttempt=0`、0 有效/下游输出，且没有 token、API credit 或现金报告。由此排除知识库内容过滤和用户自设 Guardrail，根因是 OpenRouter 对该账户/出口区域不提供 `openai/gpt-5.6-sol`；Bedrock 备用使用同一模型，不能绕过模型地域资格。下一步应选择当前区域正式可用的回答模型或合法可用的服务端入口，而不是继续放宽本地费用控制。
