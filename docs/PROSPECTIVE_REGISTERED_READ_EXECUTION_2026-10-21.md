# 前瞻候选注册只读执行接线

既有 MA24-06；当前范围仍为 G01–G13。未增加真实付费调用、部署或启用授权。

## 本轮实现

- 服务器为新前瞻任务绑定 `readExecution=registered-live-read-v1`，要求任务前捕获 ID/投影哈希存在，且不能标为安全夹具。该标记进入既有任务规格哈希和模型/图检查点绑定；不把旧保存结果解释为新的实时执行证据。
- 历史/固定安全案例保留保存结果回放语义。前瞻业务读取通过同一注册调度器调用实际只读处理函数，保留任务/租约、角色、模式、知识范围、工具版本和幂等回执边界。虚拟候选 Skill 仅改变本次可读指令，不启用账户 Skill。
- 接线沿用原始证据资格检查中已有来源合同的工具范围。没有对应来源校验合同的读取在执行前拒绝，写入效果仍拒绝；不通过新增允许项扩大已授权业务或付费请求。
- 图在模型前后及后续工具前，将已消费消息传给来源检查；知识、记忆、邮件/时间线与非虚拟 Skill 使用现有来源守卫，虚拟候选仍由冻结版本检查。失败分支保留部分/未知回执，不用无效来源伪装为成功。
- 独立审计对前瞻任务使用候选自己的权威工具日志，核对实际模型请求消费的 wire 结果，并在重建前后重新校验来源；不要求新查询与原任务入参相同。历史审计仍要求匹配保存结果，不能互换。
- 审核材料现有双臂回执读取会带出候选新读取；此前已接入候选邮件/客户来源锁。完整运行资格及最终启用来源生命周期仍须继续验证。
- 模型调用前后及独立重建时增加外发差分检查。私有结果只能是原已消费结果在相同字段路径上的严格结构子集，数组必须保留完整记录；新私有行、字符串片段、字段拼接和额外私有元数据均拒绝。该检查不代替原任务/候选指令的调用授权，也不授予新预算。
- 新知识内容须由当前数据库解析到全部原件，均为已登记、活动共享、明确 `externally_disclosable` 且 `public-*` 来源；仅有调用方“公开”标签、无原件的数据库结果均不通过。沿用公开内容敏感信息检查，只豁免格式已校验的系统定位字段；扫描不改写实际模型输入。外发边界失败单独记录停止原因，不误报模型服务故障。
