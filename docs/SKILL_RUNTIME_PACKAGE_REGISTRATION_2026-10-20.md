
应用登记只读查询不使用运维连接。发生错误时先按请求 UUID 对账，不自动补发新 UUID。包登记不改变密钥登记，也不启用 Skill。

## 本阶段实现

沿用 MA24-06，不新增用户确认或默认有效期。运行包登记是可信运行资格的必要组件，不能单独证明提供方身份、真实质量或允许启用。

- 原任务和评测的已验签成功/失败尝试保留数据库日志的开始与完成时间；声明保留已签发的 `issuedAt`。同一密钥与用途合并最早开始、最晚结束，覆盖摘要升级为 v2 并包含时间。
- 迁移 159 新增追加式登记及撤销记录。每个密钥/用途有独立版本；请求 UUID 支持精确幂等，预期版本用于拒绝覆盖并发更新。应用与采集器角色只能读取，无登记、撤销或历史修改权限；运维原生函数不使用 SECURITY DEFINER。
- 所有写入语句在执行前取得独占事务锁；最终准备读取取得共享事务锁并保留到调用者提交。读取不排队等待发布，避免与已持有的业务来源锁形成锁序环。
- 最终准备只取最新登记。撤销、缺失、过期、当前公钥/采集器/部署包或源码指纹不一致均不能退回旧登记。
- 登记必须早于相应尝试开始；比较使用数据库原始 `registered_at` 精度。整个使用区间及最终数据库复核时刻必须处于登记有效期内；有效期不超过密钥有效期。最终公共截止时间纳入包截止时间。
- 非数据库登记模式、缺迁移或登记记录返回明确未登记状态；不授予生产资格。合成无签名材料不宣称登记通过。
