本阶段继续执行已确认的 B07/B26（P06）单项超界处理。现有重复整段文本字典和字段表均不足时，评分 Agent 仅对单家公司证据标题、摘录和角色事实陈述中的重复短语建立 `exact-shared-phrase-v1` 字典。标记在请求中附有原文及明确还原指令；每条证据 ID、URL、来源、每个事实、引用、状态和顺序保留，原始候选不变。只有按实际完整请求序列化后字节数变小才采用，之后仍按主路由及获准备用路由的最大请求字节检查。批次上限、评分规则、搜索范围、费用合同和缓存身份原则不变。
