## 用户确认与边界

用户明确确认：“可以发送，产品中除了API密钥、个人信息等敏感信息，只要是公开信息或者从公开渠道取得的信息，都可以向外部发送。”本阶段将其登记为 A30。它允许把公开或从公开渠道取得的业务资料发送给外部服务，但不允许把 API 密钥、个人信息或其他敏感信息作为模型输入外发。确认不等于所有产品外发入口均已完成实现或验收。

当前 Terra 复核包只选择公司名称/域名/官网、公开证据 URL、标题和摘录、结构化业务发现、市场目标、Cudy 匹配摘要及版本化评分规则。复核入口新增递归外发副本：邮箱、带标签或国际 `+` 号的电话号码、中国手机号、凭据赋值、私钥、证件号和支付卡号形态会被替换；本地证据对象不改写，公开 URL 和时间戳保留。API 凭据不进入模型请求体；协议认证只由现有适配器发送给指定 OpenRouter 端点。
