## 邮件连接的后续阻碍

账号范围内同步日志显示“邮件服务器解析到了非公网地址”。系统及普通 UDP DNS 将阿里企业邮箱 IMAP 域名解析为 `198.18.0.123`，属于应拒绝的非公网地址。通过本机代理向阿里公共 DNS 的 HTTPS JSON 接口查询同域名，得到公网地址。新增显式配置 `MAILBOX_DNS_MODE=alidns-doh`；默认仍为 `system`。HTTPS DNS 仅传递服务器域名，固定访问 `dns.alidns.com` 并沿 MA19 固定 HTTP API 规则走 `MODEL_PROXY_URL`，4 秒超时、禁止重定向、校验问题域名/记录类型/别名链及公网地址，连接继续固定解析后地址并校验证书域名。本机已启用该模式，环境文件不提交。

DNS 解析后，授权的指定日期 INBOX 同步在 IMAP 993 TLS 握手阶段返回 `ECONNRESET`。另以公网地址及原域名各做一次经本机代理的无凭据 TLS 探针，同样返回 `ECONNRESET`；CONNECT 成功不代表 IMAP TLS 成功。尚未恢复邮箱传输，未取得目标期间邮件，也未声称生成该期间简报。没有关闭公网地址保护或 TLS 证书校验。

验证：邮件地址校验、SMTP 传输、HTTP 路由三组共 17 项测试通过；定向 ESLint 通过。覆盖 HTTPS DNS 返回私网/fake-IP/非法地址、错误状态、截断响应、域名不匹配、无关联记录及别名链。真实同步失败记录保留在当前账号，不提交邮件正文或凭据。
