# G09 新协议统一材料与来源保留

对应 MA24-06，无新增用户确认。历史材料收集、候选校验与既有审核读取支持带 `taskId` 的正式候选任务引用；新引用必须有服务器冻结记录，审核失败不会转用旧回放。

## 材料链路

- 新审计投影包含逐步路由、完成任务摘要与正式工具记录摘要，收集器保存原任务/评测/隐藏任务的精确引用；此类收集记录使用 `historical-collector-v2`。
- 存储复核重新加载并重建对应新协议执行，核对原基线、观察、路由与引用摘要。旧引用继续使用原审核协议。
- 审核材料提供原问题、两臂最终答案、原回执和候选实际消费的正式回执，附两臂标记。不会返回模型系统提示、未消费记录或其他账号资料。材料装配后复查新任务、模型、工具记录与原来源。
- 材料可供人工判定，不生成默认质量判断、生产资格或启用授权。尚未切换配置采集入口。

## 锁与持续来源指纹

隐藏任务ID不替代原任务ID：原任务继续负责原提示、附件和执行身份，新任务负责自己的状态、结果和工具日志。

统一持锁材料读取在原任务锁之后取得新任务UPDATE行锁与工具SHARE行锁，检查账号、完成态、schema、冻结、题目、原任务/评测、Skill版本及只读记录。应用侧验收来源指纹纳入隐藏任务和工具记录的完整服务器快照。新任务变化会改变该指纹；原协议没有隐藏任务时保持原指纹内容。

上述仅保留来源锁和指纹，不代表SQL激活封存、完整Worker执行等价或真实质量已通过。
