## 本轮夹具

- `MA24_CONFIGURED_RUNTIME_CRASH_KIND` 可选 historical/prospective，默认历史，其他值拒绝。
- Linux 固定镜像组合将选择值传入归档夹具，分别汇总对应恢复证明，不把历史结果当成前瞻结果。
- 前瞻进程在实际只读调用提交后、图仍有该待处理调用时 SIGKILL；Linux 明确核对终止信号。
- 提前接管必须拒绝，原任务/私有租约自然到期后才启动恢复进程；不更新期限或制造完成回执。
- 恢复后模型/工具原行完整快照保持不变，已完成步骤的重复 HTTP 会导致夹具失败；任务执行规格保持一致，核对原捕获 ID 和投影哈希。
