# 阶段111：公开费率暂停时的用量口径

修正 Sol、DeepSeek Flash/Pro 和 Brave/Tavily/Exa/Places 公开价证刷新观测。原实现对 Sol/DeepSeek 的 `review-required` 页仍记有效、已下游使用；三组来源在先前 `hold=true`、本次页面恢复一致时，仍把未解除暂停的价证记为下游使用。这使效率台账高估可用产出，虽然费用门禁始终保持暂停。

现在生成量表示收到可记录价证，有效量只表示本次公开合同与静态基线一致；下游使用量要求有效且无粘性暂停。`review-required`、证据缺失和“本次一致但旧暂停待人工复核”分别记丢弃原因，利用率按实际下游使用量计算。真实静态费率、价证快照、暂停状态、预留与历史费用不变；一致页面不会自动清除旧暂停。此变更只修正以后追加的刷新观测，不回写旧遥测。

定向15项测试覆盖三组来源的正常、漂移、粘性暂停后再次一致及故障；全量962项测试/202文件、typecheck、生产构建及全库 lint（0错误/11条既有警告）通过。测试使用合成价证与内存 SQL mock；真实公共 GET、业务搜索、模型、邮件和付费调用均为0，真实用户采用未知。本阶段实际业务输入/有效输出/下游使用均0，token、API credits、现金、重试均0；合成测试的生成/有效/下游使用计数只用于断言，测试延迟不当作供应商延迟。优化机会是单独完成人工复核流程，并在真实刷新后验证新观测行与暂停状态一致；Places 现有暂停保持。

此为 A05/A08 已授权费用与遥测修复，不是新产品规则或费率确认；A11 最小真实闭环及其他供应商完整上界仍缺。
