# 当前决策记忆的有效期复核

## 写入与新增记录门禁

迁移 148 为当前/历史记忆、版本、观察、冲突及旧共享政策表增加语句级写入门禁。普通账号写入先取得共享全局门禁和本账号排他门禁；管理员、无账号上下文、旧共享政策写入及 TRUNCATE 取得全局排他门禁。全局记忆行及版本另按真实父级 scope 校验全局门禁，不仅依赖会话角色。语句门禁先于行锁，避免同账号写入先占行再等待验收。

持锁证据入口先取得共享全局与本账号排他门禁，再锁审核包、冻结、Skill 和具体来源。此后仍执行既有来源内容与时效复核。缺迁移时直接拒绝。另一账号普通私有记忆可写入；共享政策和管理员写入会等待验收事务结束。

[实际验收](evidence/ma24-g09-decision-memory-write-gate-2026-10-17.json)通过同账号改写、新增观察和共享政策改写等待、释放后恢复，以及另一账号完整私有记忆写入继续；等待观测包含间接阻塞链。锁内策略实际数据库回归、35 项测试、类型/lint 通过。完整材料组合、知识来源、最后提交前时效及生产仍未完成。

`loadMemory` 对当前偏好与政策的 `valid_from`、`valid_until` 使用数据库检查时刻 `clock_timestamp()`。这也适用于最终 Skill 材料复核绑定到同一事务的读取，避免事务开始时间让已过期记忆继续有效，或让刚生效记忆继续不可见。历史双时间查询仍按其指定时点执行。

[实际数据库验收](evidence/ma24-g03-g09-memory-wall-clock-2026-10-17.json)在一个绑定事务内读取两条合成偏好，等待跨过有效期边界后再读。旧事务时钟仍早于到期时间，但当前读取已移除过期项、加入新生效项；已有决策记忆守卫拒绝旧快照。跨账号不可见，14 项守卫回归、类型/lint 和既有来源并发回归通过。

这证明读取时刻的有效性，不构成提交前的有效性租约。最终启用仍需在同一事务的最后检查中复核时效，记忆写入/共享政策并发和其他来源锁仍待完成。未调用模型、部署生产或开放自动启用。
