# G09 显式原件快照基础（2026-10-19）

## 实现

迁移 156 新增数据库字节快照；内部 `captureImmutableKnowledgeAsset` 在绑定账号事务及既有 149 来源 admission 下读取登记原文件，核对描述符、路径、哈希与长度后保存。相同 asset/hash 重复捕获复用同一 ID。文件读取期间变动拒绝；后续文件篡改不改变已存字节。

沿用上传路径的 50 MiB 上限，仅限制本快照入口；不改变历史资产登记上限。快照表校验实际字节长度与 SHA-256，应用角色只有 SELECT 和受限捕获函数执行权，没有直接写权限。UPDATE/DELETE/TRUNCATE 另有语句级拒绝触发器。数据库所有者/超级用户可修改或禁用机制，不宣称抵抗宿主机或数据库管理员。

读取受当前 RLS 约束：资料仍 active、资产 registered、登记哈希和长度一致、调用者为所有者或当前共享可见。资料删除不受快照外键阻挡，孤立快照不可由应用读取。返回字节再次核对长度和哈希。

## 验收

`npx tsx scripts/verify-immutable-asset-snapshot-clone.ts` 在已核名的本机 MA11 隔离克隆中，以实际 148/149/156 迁移和临时合成文件运行。所有迁移及数据库夹具均在单个事务内回滚，临时文件删除；无模型或外部网络调用。

九组通过：实际文件捕获/重复 ID/字节回读；错误哈希与长度和应用直接写拒绝；私有跨账号读及捕获拒绝；共享转私有；文件篡改拒绝但快照不变；归档及登记哈希/长度变化拒读；撤销拒读与重捕获；管理连接普通改写仍被触发器拒绝；删除登记不受阻且孤立快照不可读。

已有 descriptor/附件回归 20 项通过，类型检查和定向 lint 通过。首次沙箱连接被拒、旧克隆缺依赖及夹具 UUID 类型失败均已修正后重跑；不作为成功证据。

## 后续：G09 材料重建接线

附件及知识原件回执重建现额外读取数据库快照，返回覆盖数量和仅含 ID/hash/长度的清单哈希。最终 readiness 再次比对两类快照的覆盖数量与清单哈希，变化拒绝；不向调用方暴露原文字节。现有文件哈希检查及只读挂载检查保留，不把新快照计数替代为来源全部保护或启用批准。

历史克隆缺少 156 表，或当前资产没有已捕获快照时，明确返回零覆盖；仅对缺表做目录查询，不吞掉权限、完整性或数据库错误。没有自动创建快照。当前重建仍要求登记的文件字节匹配，文件丢失或篡改不能凭快照绕过；尚未将所有实际模型附件读取切换到数据库快照。

新增接线后，65 项定向测试通过（包括快照错误传播与最终覆盖/身份变化拒绝），实际克隆中附件和知识原件回执均得到同一快照清单哈希；原九组验证仍通过，合计十组。迁移及夹具仍全部回滚。[数据库接线收据](evidence/ma24-g09-immutable-snapshot-wiring-2026-10-19.json)。类型及定向 lint 通过。

## 后续：实际下载入口

核对实际模型协议后确认：`initialTaskMessages` 只附上登记资产 ID，`knowledge_originals` 返回元数据和下载链接；当前模型请求并不直接承载原件二进制。此前“模型附件读取切换”的待办表述不准确，不新增不存在的二进制模型接口。

原件 GET 现优先在绑定账号事务中读取已存在快照，无快照时沿用现有文件核验；不自动捕获。两条路径均核对完整字节长度/哈希，并在返回前重查资料 active、登记 registered、当前账号可见及登记身份。快照失败返回不可用，不降级绕过完整性错误。快照允许在原路径丢失或篡改后继续下载同一已登记原文；登记撤销、归档或权限收回仍拒绝。Range 与 no-store 响应保持。

21 项下载/范围边界测试通过，新增五项快照分支；类型和定向 lint 通过。[收据](evidence/ma24-g09-immutable-snapshot-download-2026-10-19.json)。这些是源代码路由调用测试，登录/快照依赖模拟；实际数据库服务已由前一阶段验证，当前新路径尚未经过编译镜像 HTTP 联验，不合并宣称生产通过。

## 当前剩余

- 未迁移业务数据库、未自动复制历史资料，无 HTTP 捕获入口。
- 已接入附件及知识原件回执重建和普通下载；未接入完整来源资格判断和最终启用事务；已有镜像不包含此功能。
- 快照不是独立质量、生产运行身份或人工审核证明；自动启用仍关闭。
- 孤立数据保留/合规删除/特权清理机制尚未实现，生产接入前必须明确；当前触发器有意阻止普通删除。
- 下一阶段需接通实际验收读取与撤销锁、处理保留生命周期，并验证并发及完整材料组合；本阶段仅完成存储基础。
