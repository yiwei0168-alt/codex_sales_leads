# 条件复核逐调用检查点与跨进程 SQL 验收（阶段133）

图的 `review_assessment_anomalies` 节点此前整批完成才保存结果。若公司 A 的 Terra 二次复核已付费完成、公司 B 因费用暂停，或 Terra 完成后 Sol 裁决暂停，账本虽能阻止相同请求再次外发，却没有可供恢复的结构化输出。本阶段在每条二次复核或裁决的输出通过 schema 与公司 ID 校验后立即保存检查点；启用持久检查点的复核队列串行执行，下一条模型请求只能在保存成功后开始。未使用持久检查点的调用仍保持原可配置并发。缓存读取/写入故障暂停，不把技术失败转成业务评分。相同用户与工作区内也按国家和公司隔离。

复用身份包含当前兼容适配器的完整序列化请求、HTTPS 端点、非凭据请求头、模型、schema、输出上限和提示输入的 SHA-256。裁决键再绑定本次二次复核请求键，因而主评分、角色证据、国家、评分策略或模型请求变化会重新核对。密钥不进入身份。复用输出不再次计入本次生成的模型 token；阶段指标单列复核与裁决复用次数。原账本预留和历史未知费用不因缓存命中释放或归零。

迁移 `066_lead_review_checkpoint.sql` 仅新增检查点表，旧任务和表不被重写；应用角色只有读取、插入权限，强制 RLS 验证工作区拥有者。迁移完整重复执行后权限仍保持只读/追加式：早期迁移会重授 public 表权限，因此本迁移末尾显式撤销更新与删除。回退应用代码时可保留该表供旧费用核对；只有确认没有需要恢复的检查点后才可由迁移管理员删除表。上线先执行迁移、再启用图代码。

验证：定向合成 Agent 覆盖后续公司预算暂停、裁决暂停、证据变化失效、保存失败停止后续请求，以及结构缺项不转成已复核主评分。真实应用数据库以隔离测试账号写入 1 条模拟响应，另一 OS 进程按相同身份读取 1 条；重复插入仍 1 条，跨用户、跨国家读取 0，其他工作区插入及应用更新均被拒绝，夹具已清理。迁移 001–066 重复执行通过；全量 976 项/203 文件、类型检查、生产构建、lint 0 错误/11 既有警告及生产依赖审计 0 漏洞。没有真实模型、搜索、邮件调用或新增付费。

边界：本阶段没有让 Terra/Sol 费用合同获准；当前请求仍按阶段132被费用门禁拒绝。SQL 跨进程核对的是产品检查点读写，Agent 暂停/恢复为合成内存夹具，尚未把两者与真实付费图任务合成同一条跨进程业务链。已记账而在检查点写入前丢失的成功响应仍须人工核对，不自动重放；同任务恢复后的早期模型用量依赖账本核对，图本次调用用量只统计新调用。真实供应商结构遵从、可信账单和 A11 自然语言闭环仍未验收。
