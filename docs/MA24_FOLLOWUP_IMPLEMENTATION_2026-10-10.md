## 1. 权限拒绝与澄清

新三模式任务固定 `agent-mode-prompts-v1.1.0`，明确未经授权的跨账号私有请求必须拒绝，不得替换成资料不足。缺型号/标题/唯一上下文指代时先澄清，版本歧义须说明；没有增加意图分类模型或恢复旧意图路由。已保存 v1.0.0 配置仍可解析并取得旧 Prompt，恢复中的消息快照保持不变。

`knowledge_originals` 没有明确标题或资产 ID 时不查询数据库；当前账号不能读取的 ID（含不存在、撤销、范围外）统一返回不透露对象存在性的拒绝。标题无匹配返回有限范围的资料不足，多结果要求选择。查询应用服务端集合范围、活动状态、注册来源及已存在的当前树版本限制。输出仅有认证下载入口，没有本地路径。

44 项相关合成测试通过，覆盖空目标零查询、不可访问 ID、无匹配、身份/范围参数注入拒绝、多结果、历史 Prompt 固定及模式边界。这是代码契约与模拟工具验证，不是所有供应商在真实问题上的拒绝质量评测。原件工具返回结构从数组改为带 kind 的对象，供主 Agent 使用；不修改资料库页面 API。
