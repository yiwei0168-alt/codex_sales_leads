# Inline 执行的汇率刷新

阶段76补齐 A05/A10：原有 ECB 每日刷新仅由独立 worker 调度；inline 模型报价原先只读缓存。现在 Kimi 中国文本和北京 Embedding 的默认报价入口先调用共享刷新，再读取独立验证的当前参考值。预算页面读取仍不触发外部刷新。

复用现有 PostgreSQL advisory lock、成功后24小时/失败后1小时重试间隔和追加式观测。刷新异常不改旧快照日期，有效缓存仍可使用；缺失或达到72小时仍拒绝报价。5%保守预留缓冲、已审核模型费率及请求契约均保持原值，没有新增模型或路由授权。模型/搜索费率自动刷新与变更确认仍未完成。

验证：

- 845 tests / 186 files、生产构建含类型检查、改动文件 lint、工作流生成检查通过。新增测试覆盖两类默认报价实际调用刷新包装器、同一观测时间、刷新失败后缓存回退、缺失参考拒绝及读取故障；原共享锁/每日及失败退避、过期测试保留。
- `scripts/verify-inline-fx-bound.ts` 使用应用数据库及真实默认报价实现，两类并发报价和各一次重复报价通过。本次新增刷新观测0，复用有效公共缓存；没有修改下一刷新时间来制造外部请求，不据此宣称本轮实际执行了到期网络刷新。
- 无模型调用、付费请求、发信或原队列认领。无 schema/费率配置变更；无需清理公共历史快照。

效率：每天共享一次成功的免费参考源请求，避免按用户/模型重复获取；实际刷新沿用已有聚合 input/output、token/API0、HTTP次数、延迟、失败原因与利用率观测。报价缓存读取不计用户采用，不增加模型费用。本轮验证公共 HTTP 调用0；整体验收和真实业务闭环仍未完成。
