# 暂停恢复时的证据依赖重验（阶段89）

已保存部分结果的恢复任务每次由生产执行器继续时，先核对原任务来源、预算和未核销付费请求，再读取当前证据有效期。新增长期暂停检查：对中间检查点中的证据重新核对当前运行绑定、内容哈希、采集日期、现行评分政策的期限，以及所引用公共文档版本是否仍有效且未被替代。原运行的重验证据同时使用来源快照的有效期和公共文档状态。缺失或异常日期不延长有效期。

若某公司证据过期或无法核实，检查点将其证据标为陈旧，撤销该公司的旧校正、评分、复核和交接派生结果，并从专用恢复证据节点继续。若该公司仍有当前有效的新证据，先用这些事实重新校正和评分；没有有效证据才进入补证队列。原候选身份、原范围、已完成其他公司、已花额度和模型用量不清零；补证失败仍暂停，不标记业务不合格，也不启动新公司发现。重验结果写入工作流阶段指标，输入/有效/下游使用数量、延迟、重试、丢弃原因与优化机会可核对；重验本身无模型、搜索和现金费用。

验证：确定性用例覆盖未过期不重跑、原证据新到期、仍有新事实时只重算决策、新事实到期或日期在未来、公共文档版本失效、重复恢复幂等；LangGraph 检查点验证受影响状态回到专用补证节点。888项测试/195文件、生产构建、局部 lint、隔离 PostgreSQL 恢复来源/预算及缺失公共版本查询、3017生产Chrome桌面/移动56组通过，测试 fixture 已清理。未进行新模型/搜索调用或真实付费。

本阶段未实际制造生产公共文档版本替换或供应商响应；这些分支为确定性测试。当前修复覆盖暂停后的证据失效；完整真实业务闭环、其他工作流依赖变化、费用入口和最终整体验收仍按当前矩阵继续。
