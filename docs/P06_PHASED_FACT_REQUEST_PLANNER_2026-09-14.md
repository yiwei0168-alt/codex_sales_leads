# 阶段149：P06 超界公司分阶段事实请求规划

对单次评分请求仍超限的公司，新增独立、无外发的 `qualification-fact-phase-v1` 规划器。它按原校正事实顺序逐条加入阶段请求，并补入所有未被事实引用的本轮有效来源；每条事实连同其本轮证据引用一起拆分，保证每一阶段证据闭合。用实际提供方请求序列化字节逐步检查更保守的 57,344 字节上限；单条事实及必要来源也超界时，在任何请求外发前抛出技术超界错误。阶段请求只要求逐事实/独立来源的简短、有引用、有未知状态的信号，不输出合格、分数或合作路径。完整候选、全部原始证据及事实未改动。

每个阶段输入携带绑定用户任务所需的国家、目标、模型、市场计划、完整当前证据和校正结果的来源指纹；提示版本也是指纹一部分。后续的阶段结果缓存还须用实际请求契约、用户/工作区/国家作用域和已核销费用状态约束，不能仅凭这个指纹重放。规划器只构造请求，本阶段**未连接评分 Agent、未执行阶段模型、未保存阶段结果，也未完成最终评分**；这些是下一步实现和验收的必需项。

合成测试以 1 家公司、151 条校正事实（其中一条冲突）和 152 条本轮证据（含一条未引用来源）为输入，规划出多个请求，每个使用现行 DeepSeek 序列化后的字节数均不超过 57,344；事实 ID 精确覆盖且保持顺序，证据 ID 全覆盖，引用均在同一阶段可见，冲突来源原文保留。修改证据或国家使来源指纹变化。单条 100,000 字符证据仍在外发前停止，保持技术未完成。全量 989 项/204 文件测试、类型检查随生产构建、改动文件 ESLint 均通过。

效率口径：阶段规划输入 1 家/151 事实/152 有效证据，输出多个有效边界内请求方案，事实和来源覆盖率均为 100%；模型有效输出、下游实际采用与用户采用分别为 0、0、未知。真实 token/API credits/现金/外部重试 0，供应商延迟与实际节省未知；定向本地测试约 75 毫秒，完整回归约 22 秒。单条超界是技术阻止而非业务丢弃。优化机会是对阶段结果做严格逐 ID 校验及可恢复持久化，再进行全阶段综合和最终评分；不得把“可规划”记为 P06 完成或市场填充能力。
