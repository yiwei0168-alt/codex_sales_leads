# MA24 锁定集检索预检

冻结的 `rag-v3-rrf-v1.0.0` 配置和 50 条 Gold 未改变。[逐题只读收据](evidence/ma24-holdout-degraded-retrieval-preflight-2026-09-30.json)对其中 44 道需路由到资料的题，分别调用当前无向量文档候选和活动 v3 release 的 `hybridSearch`。v3 此次查询向量均为 `null`，因此只运行事实和全文通道；没有调用外部 embedding 或答案模型，也没有切换生产主路。

以 Gold 所需原件的 SHA-256 是否全部进入候选衡量，无向量主路为 **41/44**，降级 v3 为 **40/44**。两者均漏 `boundary-5-04`、`boundary-5-05`、`boundary-5-07` 三道无具体型号的抽象概念题；降级 v3 另漏 `boundary-5-03`。此结果只识别文档候选缺口，不是同等配置的 v3 基线，更不是回答正确数或精确来源坐标正确数。

正式切换门槛仍要求冻结集同题的答案和精确引用均不低于完整 v3，并在长文档、跨文档与真实新增资料上改善；正式事实与无答案题不得退步。本轮未完成该门槛。现有 BGE-M3 查询服务未运行，Qwen 查询向量及 Kimi 答案生成会产生现有外部模型调用，计划本身不授权新增付费调用。下一阶段先补可复现的答案与引用影子评测输入及人工复核界面，再按实际调用范围取得授权后运行完整对照。
