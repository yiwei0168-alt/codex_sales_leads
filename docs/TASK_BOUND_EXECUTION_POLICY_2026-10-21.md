# 候选任务执行额度绑定

既有 MA24-06；当前范围 G01–G13。没有新增调用授权、预算或启用许可。

## 实现

新隐藏任务由服务器生成 `executionPolicy`，包含协议 `registered-read-trial-limits-v1`、模型决策额度、80 步图限制及递归上限 400。模型决策额度仍为 1–64、默认 8；路由尝试继续逐次接受既有付费准入检查。

- 策略进入任务规格哈希、请求幂等键及既有模型/图绑定。调用者只能选择已有范围内的额度，不能提交任意策略或证明对象。
- 同一账号/评估/臂的创建使用事务级锁，核对已存任务规格、输入和模型配置；一致则复用，额度或其他选择变化则拒绝，不创建第二个任务。
- 配置执行入口向任务创建、认领、运行和结算传递同一额度。运行参数与任务选择不一致时，在租约/请求之前拒绝。
- 审核回读从自有已完成任务取得额度，再重建并逐项核对完整规格/输入/配置。缺策略不按旧默认值补标签；显式不一致额度拒绝。
- 独立审计按已绑定额度重建，不再以实际完成决策数代替上限；策略进入审计投影。

这项绑定不证明候选与普通任务的所有额度/控制行为等价，`productionAgentEquivalent` 和自动启用仍未开放。
