# MA24 引用完整性与返回前回校修复

## 本阶段实施

- 产品 `answerWithRag` 返回完整的已引用证据块，不再把前 260 字符当作完整引用。保留已有来源坐标及事实核验标记；完整块本身仍不等于每项主张已被证明。
- 外发脱敏保留严格 UUID 格式的系统 chunk ID 和内部资产 URL，正文、标题、问题及元数据继续脱敏。数字较多的 UUID 不再被银行卡号规则破坏；正文中同样的字符串不获得豁免。
- 新检索与缓存命中均在调用外部模型前重新检查账号权限和来源；生成结束后对所有输入块再次检查，包括没有被模型引用的块。任一失效时整段生成答案及引用不返回，也不将该答案写入 RAG 查询日志；返回明确的权限/版本变化提示及正常共享途径。
- v3 来源回校增加原件注册状态、release 来源哈希以及已有当前树版本的一致性检查。没有树的历史 v3 资料仍遵守活动 release、注册来源哈希和账号权限检查，不强制新建树。遗留非 v3 路径仍保留原有 ACL 检查。

旧冻结评测脚本的 180 字符导出、通用资料不足分支及固定选块属于历史评测流程，本阶段没有改动或重跑。跨文档证据覆盖与通用权限拒绝仍待新流程修复；不能把本阶段局部安全修复记成整套权限验收通过。没有恢复旧意图识别，也没有改模型路由或切换检索主路。

## 验证

- 6 个相关测试文件、26 项通过。新增合成用例覆盖长块尾部限定条件、数字 UUID、敏感正文仍脱敏、新结果及缓存撤权、模型生成期间未引用来源撤权后整段答案停止返回。使用独立合成资料，无锁定题调参、无付费调用。
- `tsc --noEmit` 和改动文件 ESLint 通过。
- 本机 PostgreSQL 只读检查：3 个当前已注册共享原件通过回校，不存在的来源被拒绝，外部调用 0。真实数据库检查不包含并发撤权写入；撤权时序由模拟依赖测试验证。
- 本阶段为代码与本地验证完成；未重启产品服务，尚无新版本浏览器或真实模型质量验收。MA24 总发布门槛继续阻断，冻结判决与历史聚合分数保留。
