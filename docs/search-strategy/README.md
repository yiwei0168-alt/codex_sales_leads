## 维护约定

1. 每次确认、修改或优化混合搜索策略时，同一提交必须更新当前策略、决策记录和变更日志。
2. 真实搜索、A/B或工具测评必须绑定策略版本、输入指纹和运行ID。
3. GitHub只保存策略、聚合指标和无个人数据的优化结论；原始搜索正文、密钥、用户私有信息和供应商原始响应保存在数据库或受控运行产物中。
4. 搜索策略必须适配现有下游证据、角色、评分和开发工作流，不允许为某个provider创建重复补证、重复评分或独立开发策略流程。
5. 当前文档是经确认的设计记录，不代表相关多provider路由已经进入生产。
