# G09 运行等价性：源码确认的剩余差异

既有 MA24-06；G01–G13 当前范围不变。本文为实现审计，不新增用户规则，不授予运行资格或调用权限。

## 已复用的部分

普通任务与正式候选使用同一 `buildMainAgentGraph`，均同步写入已安装 PostgresSaver 协议，并由租约约束写入。候选使用隔离表和根线程，预算/轨迹与图通道一起保存。9428 的历史故障恢复及 76169 的固定启动器终态复用分别有实际收据；前瞻故障专项 73784 仍待整轮终态。

## 确认的差异及其影响

| 位置 | 当前实现 | 尚不能支持的结论 |
|---|---|---|
| `skill-runtime-candidate.ts` 的 `recordedRuntimeDispatch` | 对注册工具保留真实权限、调用日志和恢复边界，但替换工具执行函数；业务只读调用必须在原快照中找到唯一的相同工具和入参，随后返回保存的结果 | 不能证明候选进行了新的实时业务读取；历史和前瞻均走此适配器，前瞻捕获不等于实时读取执行 |
| `skill-candidate-runner.ts` 的模型预算 | 外加 1–64 次、默认 8 次模型决策上限，递归上限为该值乘 32；普通图为 80 步、递归 400 | 不能仅凭同一图函数认定所有预算和停止行为相同；也不能直接提高试验预算绕过已有授权 |
| 安全边界 | 普通任务可吸收新指令和策略修订后重规划；候选校验固定来源/冻结，并在失效时拒绝继续 | 固定输入试验的拒绝行为与在线任务的重规划不同，需要明确资格所比较的范围，不能直接宣称全部生命周期相同 |
| 固定包实际执行 | 已完成任务可以经不可变启动器/runner 成功读取；首次模型执行与故障点仍来自合成测试编译件 | 不能证明固定生产入口完成了首次提供方调用或整个试验 |
| 最终资格生产者 | `evaluateLockedSkillAcceptanceReadiness` 组合了材料、签名、运行包和来源保护；未生成 `productionAgentEquivalent=true`，最终启用要求该字段为 true | 缺口包含实际接线，不仅是等待人工审核；不能只补布尔字段或放宽最终 schema |

## 下一步实现与验证顺序

1. 明确区分历史保存结果回放与前瞻真实只读执行；前瞻接线须保持任务前捕获、独立候选日志及相同账号/知识范围，所有新读取仍受来源、权限、任务租约和既有付费准入限制。
2. 同步更新候选独立审计和材料重建，使其能够从权威候选日志重建实际读取，验证来源快照/当前性；不能把新响应直接加进旧快照后声称仍是原冻结输入。
3. 核对预算、停止、控制和来源变化的比较合同，再接资格生产者；通过当前注册包、任务和来源的服务器证据派生资格，不接受调用方声明。
4. 在实际固定入口验证新读取、恢复防重复、权限/来源失效拒绝和最终合格夹具事务；真实质量、真实提供方身份及人工判断继续单列。

不因本审计启用 Skill、不发起真实或付费调用、不推进部署或 G14–G20。现有工程收据继续保留其各自范围。
