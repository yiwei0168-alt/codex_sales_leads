# G09 检查点事务内租约保护

对应 MA24-06，属于现有恢复隔离要求的实施修复，无新增用户确认。

## 修复

外部所有权检查与检查点事务之间存在间隔。旧执行者即使已通过外部检查，延迟的检查点认领仍可能在新执行者接管后覆盖检查点令牌；仅保存时的版本 CAS 不能阻止这种重新认领。

检查点认领与保存现在先在同一数据库事务取得租约行的 `FOR SHARE NOWAIT` 锁，再核对账号、评测、arm、执行令牌、来源种类、冻结绑定、运行状态、控制字段和数据库当前时间。写入后再次核对期限，行锁保持到事务结束。租约冲突或失效即拒绝，不覆盖新执行者。缺少租约表仅兼容旧合成夹具，待验证生产来源拒绝。

回归夹具改用实际时限租约，显式跳过旧执行者的外部检查，验证延迟认领仍被 SQL 层拒绝，新检查点令牌保持不变；既有保存后恢复、终态复用、旧写、版本冲突、篡改和权限检查继续执行。
