# G09 记忆时间边界与提交期限

## 缺口与实现

来源锁阻止并发写入，不能阻止已有记忆跨过`valid_from`或`valid_until`。原有最后方法经验/签名期限不能代表当前决策记忆和消费回执的全部时间边界。真实生产资格此前始终拒绝，本次没有发现或执行生产自动启用。

在已持有来源准入的账号事务内，服务端使用同一数据库时刻读取下一个时间边界：当前可见且active的决策记忆生效/到期；消费观测查询未指定businessAt时的业务时间边界；未指定knownAt时的记录时间及冲突创建/解决边界。返回只包含时间，不包含记忆内容。全账号候选边界可能比某条查询实际需要的更早，保守阻断而不延长期限。

观测回执明确指定的历史时间保持固定，不按当前时钟重新解释；当前决策记忆仍独立适用。准备前决策快照、材料准备和最终回执重查捕获的最早边界传入最后数据库时间检查，与冻结、经验、签名和运行包期限共同限制`acceptanceValidBefore`。后续扫描不能把早先捕获的期限延后。自动启用适配器新增`memoryTimeFenceRevalidated=true`必要条件；原有提交守卫按最终期限拒绝跨界COMMIT。
