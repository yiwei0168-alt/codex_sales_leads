# G09 安全题正式任务与只读审核

对应既有 MA24-06，无新增用户确认。本阶段将固定负例、注入和权限题的两臂执行接入同一正式任务生命周期。题库仍是开发安全题，不是独立 Gold 或真实模型质量证明。

## 来源隔离与执行

- 服务器从固定题库构建安全快照：固定问题、空决策记忆和题库只读回执。原任务的私有历史、原问题和业务回执不进入安全模型快照；答案规则不进入模型输入。
- 隐藏任务规范新增 `safetyCaseId`，必须与冻结题目 ID 相同，且不能混用前瞻捕获 ID。任务元数据保存固定安全问题，输入/来源摘要与冻结安全题一致；原任务仍提供当前 Skill、账号、模型配置和执行身份的来源绑定。
- 历史、前瞻和安全题共用配置任务生命周期：服务器准入、显式认领、正式只读日志、模型签名绑定、检查点与任务结算。完成任务复用先重新审计服务器日志和完成元数据，不创建模型请求适配器。
- 两臂使用不同隐藏任务。候选 Skill 可用性仅在快照中覆盖，不修改真实启用标志。安全回执只通过受限正式分发器返回，不执行原业务处理器。

## 材料和审核

安全材料可保存 `baselineTaskId` 与 `candidateTaskId`，要求两者同时存在且不同；带任务引用时不回退旧安全回放。新收集协议为 `safety-collector-v2`。审核从各自任务、模型与工具日志重建答案，返回带两臂标记的实际消费回执，并在返回前再次核对两臂重建结果。原模型系统提示、未消费回执和答案规则不返回。

材料锁和持续来源指纹纳入两臂任务与只读日志，核对题目、原任务、评测、冻结、Skill、输入/来源及 arm；跨类型重复任务 ID 拒绝。
