# V15 quality protocol

Use the preregistered V15 execution README, unchanged 85/100 rubric and hard gates. Grade all submitted answers, including unavailable/partial replies, against actual original receipts and synthetic fixtures. Primary reviewer is the existing deep profile, first route only; one call per task per phase, no tools, fallback or retry. Known review families are development data, not fresh human Gold. Preserve all original scores, uncertainty and unknown charges. No ad hoc adjudication is registered for this run.

Frozen source includes this protocol, reviewer, audit, mechanical checks and original grade parser before product requests. First repeat uses 18 answers; repetitions use 36 new answers only if the first quality gate passes. Failed review calls remain ungraded and independent unattempted bundles continue unless HTTP 402 is observed: then no further new review is submitted. Saved 402 receipts are checked before any new submission. Missing grades make qualification incomplete; never synthesize passing scores.

Source coverage is defined by the user task, not literal boilerplate: distinguish timeline records from bodies, saved scores from recomputation, company labels from fresh role verification, and partial comparison wrappers from the actual readable originals inside them. Deduct specific factual/completeness/citation/scope/readability defects without double-counting a single phrasing concern. Accessible original document/message links and source IDs are judged in context. Final statistical comparisons require complete current billing; do not pool old results or impute unknown charges.
